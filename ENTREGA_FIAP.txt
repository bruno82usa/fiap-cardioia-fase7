RESUMO DA ARQUITETURA ENTREGUE:
- Hardware/Borda: Firmware em MicroPython no ESP32 com display OLED I2C, leitura
  analógica de BPM e Temperatura e acionamento de alarmes locais (Wokwi).
- Backend Integrador: API FastAPI em Python unificando telemetria em tempo real,
  modelo preditivo de Machine Learning (Random Forest) e assistente clínico (LLM).
- Front-End Web: Aplicação React + Vite + Tailwind CSS publicada na Vercel com
  CI/CD ativo e vercel.json configurado para Single Page Application (SPA).
- Mobile: Configuração completa para compilação .apk via Expo EAS Build
  (app.json com domínio reverso e eas.json com perfil preview).
